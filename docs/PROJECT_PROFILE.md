# Aegis Contract Intelligence — Project Profile

## GitHub description

Enterprise-grade AI contract risk analysis and compliance intelligence for non-standard agreements.

## Chinese introduction

Aegis Contract Intelligence 是一个面向非制式合同的企业级 AI 风险审查与合规智能项目。项目采用文档智能、可配置规则、混合检索与大模型推理相结合的技术路线，目标是将合同风险、适用规则、判断依据及原文位置组织成可解释、可复核、可审计的审查结果。

项目强调 AI 辅助而非替代专业判断，并将证据定位、人工复核、规则扩展与质量评估作为核心工程能力。目前项目处于架构预览阶段，代码与评测结果将按里程碑逐步开放。

## English introduction

Aegis Contract Intelligence is an enterprise-oriented AI review platform for non-standard agreements. It is designed around a hybrid architecture that combines document intelligence, configurable compliance rules, retrieval-augmented reasoning, and evidence verification.

Rather than producing opaque model-generated conclusions, Aegis aims to connect each risk finding to its applicable policy, reasoning, contractual evidence, and original source location. The project is currently in architecture preview, with implementation and evaluation assets to be released incrementally.

## Interview elevator pitch

这个项目不是把整份合同直接丢给大模型，而是把合同审查拆成多个可以验证的阶段。首先保留文档结构并为原文生成稳定定位，然后根据合同场景筛选规则和相关条款，再由模型完成语义风险判断，最后验证证据并输出结构化结果。这样能够区分确定性规则和模型推理的职责，也让每个结论都可以回到原合同复核。
